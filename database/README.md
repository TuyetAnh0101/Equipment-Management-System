# Database

This directory contains the Oracle Database scripts for the Equipment Management System.

## Contents

- `Oracle_Local.sql` - Oracle database configuration
- `QuanLy_Equipment.sql` - Database tables and main schema
- `QuanLy_Equipment_Function.sql` - Database functions
- `QuanLy_Equipment_Index.sql` - Database indexes
- `QuanLy_Equipment_Sequence.sql` - Database sequences
- `QuanLy_Equipment_StoreProcedure.sql` - Stored procedures
- `QuanLy_Equipment_Trigger.sql` - Database triggers
- `QuanLy_Equipment_View.sql` - Database views

## Database

- Oracle Database XE 21c
- Pluggable Database: XEPDB1
