# Equipment Management System

An **Oracle-based Equipment Management System** designed to streamline equipment operations, from inventory management and rentals to returns, payments, invoicing, taxation, and system auditing.

The project focuses on applying **relational database design, PL/SQL programming, business rules, and database-level automation** to model and manage real-world equipment rental workflows.

## ✨ Key Features

- 📦 **Equipment & Inventory Management** — manage equipment, categories, stock levels, and availability.
- 📝 **Rental Management** — handle rental orders, rental items, deposits, and equipment status.
- 🔄 **Return Processing** — manage returns, late fees, and equipment condition.
- 💳 **Payment & Invoice Management** — process payments and generate invoices with tax calculation.
- 🔐 **Audit & Control** — track system activities and maintain operational records.
- ⚙️ **Database Automation** — implement functions, procedures, and triggers for business rules and automated processing.

## 🛠️ Technologies

- Oracle Database
- SQL
- PL/SQL
- Relational Database Design
- Stored Procedures & Functions
- Database Triggers

## 🎯 Project Focus

The project demonstrates how **database architecture and PL/SQL programming** can be applied to build a reliable management system with structured data, automated business rules, and transaction-oriented workflows.
